# Кейс-задача № 1 — Стилистическое преобразование чисел

Учебная практика (технологическая (проектно-технологическая) практика).
Направление 02.03.03 «Математическое обеспечение и администрирование информационных систем»,
профиль «Разработка программного обеспечения (Full-stack разработка)».

## Условие

Программа последовательно запрашивает у пользователя день, месяц и год рождения, после чего:

- определяет, какому дню недели соответствует эта дата;
- определяет, был ли год високосным;
- вычисляет, сколько сейчас лет пользователю;
- выводит дату рождения в формате `дд мм гггг`, где цифры прорисованы звёздочками (`*`),
  как на электронном табло.

## Стек

Python 3.6+, только стандартная библиотека. Внешние зависимости отсутствуют.

## Запуск

```bash
python main.py
```

## Тесты

```bash
python -m unittest -v
```

15 тестов. Ключевой из них — `test_matches_standard_library`: результат собственной
реализации алгоритма Зеллера сверяется с `datetime.date.weekday()` на всех датах
с 01.01.1990 по 01.01.2030 (более 14 600 дат).

## Реализация

| Функция | Назначение |
|---|---|
| `is_leap_year(year)` | Високосность года: кратность 4, исключение для веков, кратных 100, но не 400 |
| `days_in_month(month, year)` | Число дней в месяце с поправкой на високосный февраль |
| `weekday_name(day, month, year)` | День недели по конгруэнции Зеллера — чисто арифметически, без модуля `datetime` |
| `calculate_age(day, month, year)` | Полное число лет; год вычитается, если день рождения в текущем году ещё не наступил |
| `render_number(text)` | Отрисовка строки цифр шрифтом 5×7 из символов `*` |
| `format_date_as_display(...)` | Сборка строки `дд мм гггг` и передача её в отрисовку |
| `ask_int` / `read_birth_date` | Ввод с валидацией: тип, диапазон, существование даты, отсутствие даты из будущего |

### Обработка некорректного ввода

- нечисловое значение — повторный запрос;
- значение вне диапазона — повторный запрос с указанием границ;
- несуществующая дата (например, 31.02) — сообщение с реальным числом дней в месяце;
- дата из будущего — отклоняется.
